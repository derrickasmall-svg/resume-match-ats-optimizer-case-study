# Security Notes

This project was prepared for portfolio review without exposing sensitive information.

## Protected Items

The following items are intentionally excluded from the public repository:

- Source code
- API keys
- Environment files
- Node modules
- Personal resumes
- Personal job application data
- Full AI service implementation

## Safe Public Content

This repository only includes:

- Project overview
- Feature summary
- Screenshots
- Architecture documentation
- Security notes
- Skills demonstrated

## Credential Handling

API credentials are stored using environment variables and are not committed to GitHub.

## Recommended Production Improvements

- Server-side API proxy
- Authentication and authorization
- Secure user data storage
- Input validation
- Rate limiting
- Audit logging
- Secrets management
